# Academy Play V10.0.31

## Novo fundo da tela de login

- a imagem “A nova era de aquisição de clientes por Inteligência Artificial” passa a compor o fundo da tela de login;
- no desktop, a arte aparece integralmente ao lado do formulário;
- no celular, a arte fica no topo e o formulário permanece legível logo abaixo;
- convite, recuperação e redefinição de senha continuam com o fundo anterior.

Depois de substituir/criar os arquivos deste pacote na raiz do projeto, execute:

```bash
npm run build -w @academy/web
```

Reinicie o frontend depois da atualização. Não há migration nem dependências novas.
